Смена nameservers для inner-code.me

  1. Войдите в IONOS и откройте Domains & SSL → inner-code.me.
  2. Нажмите Actions / ⚙ → Name Server → Use Custom Name Servers.
  3. Удалите текущие nameservers и укажите только: kanye.ns.cloudflare.com raphaela.ns.cloudflare.com Поля Name Server 3 и 4 оставьте пустыми.
  4. Нажмите Save и сообщите нам «Готово». Другие настройки домена и DNS-записи не меняйте.
